# «Мой ТВ» — лёгкий лаунчер для Starwind SW-LED40SA301

Чистый домашний экран без рекламы и рекомендаций: часы, статус сети, большая кнопка **Happ VPN**
(зелёная, когда VPN включён), ряд избранного и сетка всех приложений. Управление только пультом.

## Что умеет
- **Кнопка Happ VPN** — сама находит Happ Plus / Happ и открывает его. Показывает, включён ли VPN прямо сейчас.
  Если Happ называется иначе — удерживайте ОК на кнопке и выберите приложение вручную.
- **Избранное** — удерживайте ОК (или кнопку «Меню») на любом приложении → «В избранное», там же «Сдвинуть влево/вправо».
- **Скрыть приложение** — то же меню → «Скрыть с экрана». Скрытые можно вернуть плиткой «Скрытые (N)».
- **О приложении / Остановить / Удалить** — из того же меню.
- Никаких фоновых служб, сети и рекламы: лаунчер ничего не грузит из интернета.

## Шаг 1. Получить APK (5 минут, бесплатно, без установки программ)
1. Зарегистрируйтесь на github.com.
2. Нажмите **+ → New repository**, имя любое (например `tv-launcher`), **Private**, Create.
3. **Add file → Upload files** → перетащите ВСЁ содержимое этой папки (вместе со скрытой папкой `.github`!) → Commit.
   - Если папку `.github` не видно: в Windows Проводник → Вид → Скрытые элементы.
4. Откройте вкладку **Actions** → сборка «Собрать APK» запустится сама (≈3–4 мин).
5. Откройте завершённую сборку (зелёная галочка) → внизу **Artifacts → MyTV-Launcher** → скачается zip с `MyTV-Launcher.apk`.

(Есть Android Studio? Можно просто открыть папку и нажать Build → Build APK.)

## Шаг 2. Включить режим разработчика на ТВ
1. **Настройки → Об устройстве** (иногда: Настройки → Устройство → Об устройстве).
2. Найдите строку **«Номер сборки»** (Build) и нажмите на неё ОК **7 раз** подряд → «Вы стали разработчиком».
3. Назад → появится **«Для разработчиков»** (в «Настройки» или «Устройство»).
4. Включите **«Отладка по USB»** и, если есть, **«Отладка по сети / ADB по Wi-Fi»**.
5. **Настройки → Безопасность → Неизвестные источники** — разрешить.
6. Посмотрите **IP телевизора**: Настройки → Сеть → ваша Wi-Fi сеть (вида `192.168.1.50`).

## Шаг 3. Установить
**Способ А — флешка (проще всего):** скопируйте `MyTV-Launcher.apk` на флешку → вставьте в ТВ →
откройте любым файловым менеджером (если нет — в стоковом магазине поставьте «X-plore» или «File Commander») → Установить.

**Способ Б — по Wi-Fi с компьютера (нужен и для чистки мусора):**
1. Скачайте Android Platform Tools: https://developer.android.com/tools/releases/platform-tools → распакуйте рядом со скриптами из папки `tools`.
2. Положите туда же `MyTV-Launcher.apk`, запустите `install.bat`, введите IP.
3. На ТВ появится «Разрешить отладку?» → **Всегда разрешать** → ОК.

## Шаг 4. Сделать лаунчер главным
Нажмите **Home** на пульте → в окне выбора «Мой ТВ» → **Всегда**.
Либо: Настройки → Приложения → Приложения по умолчанию → Главный экран.

**Если окна выбора нет** (стоковый лаунчер «не отпускает»):
1. Запустите `install.bat` — в конце он покажет имя стокового лаунчера (например `com.xxx.launcher/.MainActivity`).
2. Сначала откройте «Мой ТВ» из списка приложений и убедитесь, что он работает.
3. Отключите стоковый (обратимо):
   ```
   platform-tools\adb.exe shell pm disable-user --user 0 ИМЯ.ПАКЕТА.СТОКОВОГО.ЛАУНЧЕРА
   ```
   и запишите это имя в файл `tools\stock_launcher.txt` — чтобы `restore.bat` мог всё вернуть.
4. Нажмите Home — откроется «Мой ТВ».

## Шаг 5. Чистка и установка приложений — одной кнопкой
Папка `tools`: положите туда `MyTV-Launcher.apk` и запустите `setup.bat`. Он сам:
скачает adb, подключится к ТВ, поставит лаунчер, покажет и отключит мусор (ivi, караоке, EShare, iMirror и т.п.),
поставит YouTube без рекламы (SmartTube) и RuStore для ТВ, а также все APK из папки `tools\apk`.
Откат — `restore.bat`.

## Шаг 6. Happ
1. Поставьте **Happ для Android TV** (с официального сайта разработчика или из магазина) — так же, флешкой или
   `platform-tools\adb.exe install happ.apk`.
2. Добавьте подписку (удобнее всего отправить с телефона по QR — в Happ есть такая функция).
3. При первом подключении ТВ спросит разрешение на VPN → ОК.
4. Чтобы VPN поднимался сам после включения ТВ: в Happ включите автозапуск/автоподключение, если такой пункт есть;
   на некоторых прошивках есть Настройки → Сеть → VPN → ⚙ у Happ → «Постоянный VPN».

## Советы, чтобы ТВ не тормозил
- «Для разработчиков» → **Масштаб анимации** (все три) → 0.5x.
- Там же → **Лимит фоновых процессов** → «Не более 2 процессов».
- Раз в неделю выключайте ТВ из розетки на минуту — на этих прошивках это чистит память лучше всего.
